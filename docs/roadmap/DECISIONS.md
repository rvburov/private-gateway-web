# Согласованные решения

1. Макет v8 согласован пользователем; разрешена разработка Private Gateway Web.
2. Основа процесса — AGENTS.md из Private Gateway Client; основа веб-стека и доступа — AI Agent Capper.
3. Сайт управляет только своим кабинетом и скачиванием клиента. VPN и его учетные записи
   остаются в Private Gateway. Никаких изменений работающего VPN-сервера.
4. Дизайн главной сохраняется: текст и кнопка слева, начало на уровне панели устройств;
   оригинальная кликабельная демонстрация клиента, одинаковый размер области устройств.
5. Английский — исходный язык, русский — через переключатель; пять платформ без выдуманных выпусков.
6. Разработка и локальные проверки разрешены. Публикация согласована отдельно (п. 8).
7. 2026-11-11: пользователь выбрал оформление «Спектр» из трех насыщенных вариантов поверх v8
   (Изумруд, Полночь, Спектр). Композиция, шрифты и тексты v8 сохраняются; меняются палитра,
   фоны, градиенты и цвета платформ. Логотип остается прежним.
8. 2026-11-12: сайт работает на сервере AI Agent Capper по домену `private-gateway.duckdns.org`
   и разворачивается тем же процессом: push в master → проверки → GitHub Actions → `deploy.sh`.
   Вход — через Caddy capper (вариант «общий вход»; правка в репозитории capper, его Р31),
   без второго IP. Бэкапы — тот же ключ age владельца и бакет S3 capper, своя папка
   `private-gateway-web/`. VPN Private Gateway на этом сервере нет и он не затрагивается.
9. 2026-11-12: выпуски клиента попадают на сайт автоматически (вариант 2): workflow «Выпуск на сайт»
   в `private-gateway-client` после выпуска отправляет файлы на сервер отдельным ключом, который может
   только принять выпуск. Репозиторий клиента закрытый; участники скачивают файл с сайта после входа.
10. 2026-11-12: контроль доступа: журнал скачиваний (кто, когда, что, сеть), лимит одновременных
    входов на сайт и устройств приложения на участника, вход в приложение аккаунтом сайта
    (пароль и 2FA) с привязкой устройства. Решение о доступе — на сайте; Private Gateway и его
    профили не меняются. Платная подписка — следующим этапом на этой же модели (лимит устройств
    на участника). Защиту от декомпиляции не обещаем: секретов в клиенте нет, доступ решает сервер.
11. 2026-11-13: двухфакторная проверка — только у администраторов. Участник входит по email и
    паролю на сайте и в приложении; приглашение участника ведет сразу в кабинет, приглашение
    администратора — через обязательную настройку 2FA. У существующих участников 2FA удаляется
    без выхода из аккаунта, при понижении администратора — тоже. Участник сам меняет пароль и
    выходит на всех устройствах (администратор — с кодом 2FA). Не больше 3 новых устройств
    приложения за 30 дней (настраивается). Полное удаление участника и приглашений и
    автоматическая очистка ненужных данных. Страница скачивания ставит систему посетителя
    первой с основной кнопкой; `.apk` скачивается с телефона без проблем, рядом подсказка
    об установке.
