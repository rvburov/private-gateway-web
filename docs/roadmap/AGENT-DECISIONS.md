# Решения при разработке

| № | Решение | Альтернативы и основание |
| --- | --- | --- |
| 001 | Сохранить `mockup/` как согласованный эталон, приложение строить в `frontend/` и `backend/` | Замена макета лишила бы проект проверенного визуального источника. |
| 002 | Адаптировать AGENTS.md клиента под веб-стек | Команды .NET, TUN, firewall и тесты служб неприменимы к сайту. Облачная работа остается в собственной копии. |
| 003 | Не подключать Redis на первом этапе; хранить состояние доступа в PostgreSQL | У сайта нет очередей AI-задач Capper. Лимиты и одноразовые операции должны быть атомарны в общей БД. |
| 004 | Каталог выпусков изначально пуст; приватная выдача подключенных файлов через API | Нет утвержденных версий клиента и App Store URL. Публичные пути обходили бы отзыв доступа. |
| 005 | Проверять доступные версии пакетов и закреплять lock-файлами | Версии в исходном Capper служат ориентиром, но сборка должна использовать реально доступные пакеты. |
| 006 | Основные пакеты закреплены в тех же версиях, что в Capper | Проверка реестров подтвердила доступность версий. Универсальные Python lock-файлы сохраняют условия Windows для colorama и uvloop. |
| 007 | Caddy перезаписывает адрес клиента, API доверяет только выделенной сети прокси | Иначе один IP прокси объединяет лимиты всех посетителей; доверие любому внешнему X-Forwarded-For позволяет обходить их. |
| 008 | Подключение выпусков — отдельная CLI-команда, API читает хранилище без права записи | Реальных файлов еще нет. Управление каталогом в веб-админке расширило бы согласованный состав и поверхность загрузки файлов. |
| 009 | Проверка CI для веб-приложения на Linux и браузерных размерах | Трехплатформенные тесты VPN-служб из AGENTS.md клиента здесь неприменимы. Нативные Windows/macOS запуски не выдаются за проверенные. |
| 010 | «Спектр» оформлен токенами в `style.css` и отдельным `spectrum.css`, одинаковым в `mockup/` и `frontend/src/styles/` | Палитра остается в одном месте, правила оформления не смешиваются с разметкой v8. Варианты A и B остались только в черновике и в код не вошли. |
| 011 | Цвет платформы задается атрибутом `data-platform`, а не порядком карточек | Порядок карточек может измениться; цвет Windows, macOS, iOS, Linux и Android не должен зависеть от позиции. |
| 012 | На телефоне колонка иконки в карточке загрузки расширена до 44 px под плитку 44 × 44 | Плитка 52 px в колонке 37 px наезжала на заголовок платформы. |
| 013 | В `tests/browser-access.cjs` кнопки загрузки считаются после появления сетки | Заголовок кабинета показывается до ответа `/api/downloads`; без ожидания проверка зависела от скорости ответа. |
