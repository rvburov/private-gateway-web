## Проверки реализации

`frontend/src/account/account.test.tsx`: 10 тестов, 10 прошли, 0 ошибок, 0 пропусков. Проверены реальные состояния API: отсутствие файлов, доступный файл, ошибка каталога и повтор, скрытая административная навигация участника, выдача одноразового приглашения, отклоненный отзыв приглашения, отзыв доступа участника и пагинация поиска. `npm run typecheck` проходит.

Проверка мутантом: временно удалено ограничение домена App Store из `safeDownloadUrl`; тест безопасности ссылки упал. После восстановления исходника тот же тест проходит. Внешняя ссылка для загрузки не принимается за приватный файл, а секрет приглашения отсутствует после закрытия диалога. Это проверки на тестовых ответах API; полный сценарий с PostgreSQL проверяется отдельно при интеграции приложения.
