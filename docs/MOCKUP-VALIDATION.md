# Проверка визуального макета

Проверка выполнена в Chromium через Playwright. Для исходного многофайлового макета использовался временный статический HTTP-сервер, привязанный только к `127.0.0.1` облачной среды. Публичный сайт, backend, база данных и VPN-службы не запускались.

Проверены:

- обычный вход: пустые email/пароль → демонстрационный код 2FA → кабинет; административный экран открывается отдельно через панель просмотра макета;
- ошибочный код приглашения; регистрация `PG-DEMO` → настройка 2FA → сохранение вымышленных резервных кодов → кабинет;
- создание приглашения в админке → переход к регистрации с привязанной почтой → сохранение роли администратора через все шаги; статус приглашения становится «Использовано»;
- отклонение использованных и отозванных приглашений;
- ошибочный и правильный демонстрационный код восстановления;
- поиск и фильтрация участников, просмотр карточки, отзыв доступа с подтверждением и демонстрационной 2FA;
- создание приглашений обеих ролей, копирование кода, отзыв приглашения;
- скрытие админских разделов в роли участника и экран отказа при прямом переходе;
- выбор архитектуры macOS, открытие заглушек скачивания, отсутствие ссылки iOS;
- исходная демонстрация клиента: щит, скрытие IP, пояснения проверок, смена сервера, переходы между экранами;
- основные десять экранов на ширинах 360, 390, 768 и 1440 px: горизонтального переполнения не обнаружено;
- экранирование пользовательского ввода в поиске; ошибок JavaScript в проверенных сценариях не обнаружено.

Это проверка работы демонстрационного интерфейса. Она не проверяет и не подтверждает настоящую авторизацию, TOTP, VPN, выпуск клиентских сборок или серверное разграничение доступа — их здесь нет.

## Автономный HTML

Экспорт `Private-Gateway-Web.html` проверен отдельно: щит, скрытие IP, пояснения проверок, меню серверов, переходы Главная → Серверы → Настройки → Главная, переключение Android и переход к входу сайта. Все изображения и шрифты встроены как data URI, экраны клиента работают через srcdoc. В проверенном прогоне запросов ресурсов по сети не было (запрошен только сам HTML), ошибок JavaScript и console errors не было. Размер экспорта — около 4,29 MiB.

## Повторная проверка после замечаний пользователя

На экранах входа нет выбора роли или кнопки перехода в админку. Email и пароль изначально пустые. На компьютере показаны шесть мер проектируемой защиты; на телефоне они находятся в раскрываемом блоке.

Проверены вход → ошибка пустого кода 2FA → корректный код → кабинет, ошибочное приглашение → PG-DEMO → настройка 2FA → резервные коды → кабинет. Проверены семь затронутых маршрутов на ширинах 360, 390, 768 и 1440 px — 28 сочетаний без горизонтального переполнения и ошибок JavaScript.

Автономный `Private-Gateway-Web-v2.html` проверен отдельно: клики щита, скрытие IP, пояснения, выбор сервера, навигация клиента, Android, вход → 2FA → кабинет. Внешних запросов ресурсов и ошибок JavaScript не обнаружено.
